## ADDED Requirements

### Requirement: Update Hero Subtitle
The system MUST display the correct subtitle in the hero section of the homepage.

#### Scenario: Hero subtitle matches reference
- **WHEN** the user views the homepage
- **THEN** the subtitle below the main title must say "INVERSIÓN INTELIGENTE"
- **AND** it must be in uppercase with hero subtitle styling

### Requirement: Update Main Feature Texts
The system MUST display the correct texts in the 4-column features section.

#### Scenario: Feature section texts match reference
- **WHEN** the user views the features section
- **THEN** the four elements must display: "Localizamos", "Gestionamos", "Reformamos", "Rentabilizamos"
- **AND** they must maintain their corresponding icons

### Requirement: Update CTA Section
The system MUST display the correct text in the call-to-action section.

#### Scenario: CTA section text matches reference
- **WHEN** the user views the CTA section
- **THEN** it must display "Y podemos Financiar" with "Financiar" highlighted
- **AND** it must display "Tu Inversión Inmobiliaria"
- **AND** it must display "TÚ SOLO COBRAS" with "COBRAS" in gold color

### Requirement: Update Investment Section
The system MUST display the correct texts in the investment/financial freedom section.

#### Scenario: Investment section texts match reference
- **WHEN** the user views the investment section
- **THEN** the title must be "CONSTRUYE TU LIBERTAD FINANCIERA"
- **AND** it must display "Consigue rentabilidades de hasta el 20% o más."
- **AND** it must include the descriptive text about generating passive income

### Requirement: Update Services List
The system MUST display the correct texts for each listed service.

#### Scenario: Services list matches reference
- **WHEN** the user views the services section
- **THEN** each service must display its name and description according to the reference
- **AND** the names must be: Personal Shopper Inmobiliario, Reforma y Restauración Integral, Broker Hipotecario Personalizado, Interiorismo y Homestaging, Gestión de Alquiler y Rentabilidad, Servicio de Activos en Subasta: Rey Subastas, Servicios de Seguros para Inmuebles, Asesoría Gratuita y Club Inversor, Servicio de Limpieza Profesional: Alfa Clean

### Requirement: Update Brands Section
The system MUST display the correct sub-brand names.

#### Scenario: Brands section matches reference
- **WHEN** the user views the sub-brands section
- **THEN** it must display: FLIP ART, LUJO RENT, GRUPO ALFA SEGUROS, ALFA CLEAN, Rey Subastas, ALFA LAB

### Requirement: Update Contact Section
The system MUST display the correct text in the contact section.

#### Scenario: Contact section text matches reference
- **WHEN** the user views the contact section
- **THEN** it must display "Contáctanos" as the title
- **AND** it must display "Responderemos encantados a su consulta a la mayor brevedad posible."

## Requirements

### Requirement: Contact Page Implementation
The system SHALL implement the `/contacto` page as a faithful clone.

#### Scenario: Visit contact page
- **WHEN** user goes to `/contacto`
- **THEN** contact info and forms are displayed.

### Requirement: Form Visual Parity
Contact forms SHALL match the original visual style.

#### Scenario: Visual audit
- **WHEN** comparing forms with original site
- **THEN** styles match.

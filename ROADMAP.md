# ROADMAP

## Objetivo

Recoger todo lo que ha quedado fuera del alcance de la fase 1 de la membership platform para que no se pierda y pueda planificarse en fases posteriores.

## Fase 2 candidata

### Admin operations ampliado
- Panel interno para gestionar organizaciones, promo codes y casos de soporte.
- Herramientas de revisión manual para incidencias de atribucion, promos y referrals.
- Vistas internas para estado de miembros, incidencias de pago y revisiones operativas.

### Membership content publishing
- Sistema mas robusto para publicar recursos privados.
- Gestion editorial de masterclasses, seminarios y contenidos premium.
- Posible CMS o flujo de publicacion para contenidos del area privada.

### Membership content growth
- Biblioteca real de recursos.
- Agenda privada de eventos.
- Solicitud y gestion de citas con expertos.
- Mejora del dashboard privado con contenido vivo.

### Analytics y reporting ampliado
- Dashboards mas ricos para organizaciones.
- Reporting historico de conversiones, renovaciones y cancelaciones.
- Reporting mas profundo de referrals y cohortes.

### Antifraude ampliado
- Limites mas sofisticados por metodo de pago.
- Device fingerprinting.
- Listas de bloqueo.
- Analisis de comportamiento.
- Flujos de revision manual mas avanzados.

## Fase 3 candidata

### Billing evolution
- Plan mensual.
- Futuros planes adicionales.
- Cambios de plan mas complejos.
- Rewards o descuentos posteriores ligados a referrals.

### Auth expansion
- Google login u otros proveedores OAuth.
- Expansion de flujos de autenticacion si el negocio lo necesita.

### Organization growth
- Vanity routes o landings especificas por organizacion si mas adelante se justifican.
- Operativa mas avanzada para partners y organizaciones colaboradoras.

### Legal/compliance ampliado
- Requisitos adicionales si cambian los flujos de datos o el modelo de negocio.
- Posibles necesidades fiscales o de facturacion mas avanzadas.
- Revisiones legales si se introducen nuevos tipos de consentimiento o datos sensibles.

## Mas adelante

### Plataforma y producto
- App movil.
- Roles administrativos.
- Multi-tier memberships.
- Gamificacion.
- Sistema de puntos.
- Marketplace de rewards.
- API publica.
- Integracion CRM.

## Notas

- La fase 1 se mantiene deliberadamente simple: plan anual, auth basica, metadata minima, runtime portable, area privada MVP y operativa base.
- Todo lo anterior debe evaluarse en cambios/specs separados cuando la fase 1 este implementada y validada.
